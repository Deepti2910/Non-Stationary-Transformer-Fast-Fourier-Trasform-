# Non-Stationary-Transformer-Fast-Fourier-Trasform-


In this project, I worked on optimizing a non-stationary transformer model by introducing a series stationarization and de-stationary attention mechanism to better handle time-varying patterns in data. Using the Fast Fourier Transform (FFT),  identified the dominant frequency in the input signals to determine an adaptive window size for the training process, improving model stability and accuracy. This approach enhanced the transformer's ability to learn from dynamic, non-stationary time series data. Additionally, I gained hands-on experience in data cleaning, preprocessing, and manipulation using real-world datasets to ensure high-quality input for the model’s performance evaluation.
